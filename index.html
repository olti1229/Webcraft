""" Standoff 2 Radar – ОТЛАДОЧНАЯ ВЕРСИЯ Выводит в консоль: найденные процессы, смещения, количество игроков, их координаты. """ import ctypes from ctypes import wintypes, byref, create_string_buffer import psutil import struct import time import sys # ========== НАСТРОЙКИ (СМЕЩЕНИЯ ДЛЯ VERSION 0.38.2) ========== OFFSETS = { "entity_list": 0x06B2A1F8, "player_count": 0x06B2A1FC, "pawn_offset": 0x118, "controller_offset": 0x220, "name_offset": 0x328, "team_offset": 0x430, "pos_offset": 0x538, "health_offset": 0x640, "alive_offset": 0x748, } class MemoryReader: def __init__(self): self.handle = None self.base = 0 self.kernel32 = ctypes.WinDLL('kernel32', use_last_error=True) self.kernel32.OpenProcess.argtypes = (wintypes.DWORD, wintypes.BOOL, wintypes.DWORD) self.kernel32.OpenProcess.restype = wintypes.HANDLE self.kernel32.ReadProcessMemory.argtypes = (wintypes.HANDLE, wintypes.LPCVOID, wintypes.LPVOID, ctypes.c_size_t, ctypes.POINTER(ctypes.c_size_t)) self.kernel32.ReadProcessMemory.restype = wintypes.BOOL def connect(self): # Поиск процесса эмулятора targets = ['HD-Player.exe', 'LdVBoxHeadless.exe', 'MuMuVMMHeadless.exe', 'NemuHeadless.exe'] pid = None for proc in psutil.process_iter(['pid', 'name']): if proc.info['name'] in targets: pid = proc.info['pid'] print(f"[+] Найден процесс: {proc.info['name']} PID={pid}") break if not pid: print("[-] Эмулятор не запущен!") return False # Открываем процесс self.handle = self.kernel32.OpenProcess(0x0010, False, pid) if not self.handle: print("[-] Не удалось открыть процесс. Запустите от администратора.") return False # Базовый адрес (обычно 0x140000000 для 64-бит) self.base = 0x140000000 print(f"[+] Подключено к процессу, база = 0x{self.base:X}") return True def read_ptr(self, addr): buf = ctypes.c_uint64() bytes_read = ctypes.c_size_t() if self.kernel32.ReadProcessMemory(self.handle, addr, byref(buf), 8, byref(bytes_read)): return buf.value return 0 def read_int(self, addr): buf = ctypes.c_int() bytes_read = ctypes.c_size_t() if self.kernel32.ReadProcessMemory(self.handle, addr, byref(buf), 4, byref(bytes_read)): return buf.value return 0 def read_vector2(self, addr): buf = create_string_buffer(8) bytes_read = ctypes.c_size_t() if self.kernel32.ReadProcessMemory(self.handle, addr, buf, 8, byref(bytes_read)): x, z = struct.unpack('ff', buf.raw) return (x, z) return (0.0, 0.0) def read_string(self, addr, maxlen=32): buf = create_string_buffer(maxlen) bytes_read = ctypes.c_size_t() if self.kernel32.ReadProcessMemory(self.handle, addr, buf, maxlen, byref(bytes_read)): try: return buf.value.decode('utf-8', errors='ignore').split('\x00')[0] except: return "" return "" def get_players(self): players = [] # Читаем entity_list и player_count ent_list = self.read_ptr(self.base + OFFSETS["entity_list"]) count = self.read_int(self.base + OFFSETS["player_count"]) print(f"[DEBUG] entity_list = 0x{ent_list:X}, player_count = {count}") if not ent_list or count <= 0: return players for i in range(min(count, 64)): ent = self.read_ptr(ent_list + i * 8) if not ent: continue pawn = self.read_ptr(ent + OFFSETS["pawn_offset"]) ctrl = self.read_ptr(ent + OFFSETS["controller_offset"]) if not pawn or not ctrl: continue team = self.read_int(pawn + OFFSETS["team_offset"]) health = self.read_int(pawn + OFFSETS["health_offset"]) alive = self.read_int(pawn + OFFSETS["alive_offset"]) == 1 x, z = self.read_vector2(pawn + OFFSETS["pos_offset"]) name = self.read_string(ctrl + OFFSETS["name_offset"], 32) if name: print(f" Игрок {i}: name='{name}', team={team}, pos=({x:.1f},{z:.1f}), health={health}, alive={alive}") if (abs(x) < 10000 and abs(z) < 10000) and (x != 0 or z != 0): players.append({'name': name, 'team': team, 'x': x, 'z': z, 'health': health, 'alive': alive}) return players def close(self): if self.handle: self.kernel32.CloseHandle(self.handle) def main(): print("=== Отладка чтения памяти Standoff 2 ===\n") reader = MemoryReader() if not reader.connect(): input("Нажмите Enter для выхода...") return print("\nЧтение данных каждые 2 секунды. Находясь в матче, смотрите вывод.") print("Если игроки не появляются – обновите смещения.\n") try: while True: players = reader.get_players() print(f"--- Всего получено игроков: {len(players)} ---\n") time.sleep(2) except KeyboardInterrupt: print("\nЗавершение.") finally: reader.close() if __name__ == "__main__": main()
